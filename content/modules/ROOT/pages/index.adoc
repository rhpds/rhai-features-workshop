= Red Hat OpenShift AI 3 Features Workshop
:navtitle: Welcome

Welcome to the *Red Hat OpenShift AI 3 Features Workshop*.

In this workshop you take the role of an engineer at *Fed Aura Capital*, a mortgage lending firm running a production AI platform on Red Hat OpenShift AI. The platform is already deployed — your job is to explore, configure, and extend each layer of it across nine hands-on modules.

== What you will do

* Deploy and benchmark LLM inference with GPU acceleration
* Publish governed model endpoints and manage API access
* Design and version prompts in the GenAI Playground
* Build a predictive AutoML model for loan underwriting
* Enable RAG-grounded responses with a private policy document
* Route and fail over agentic traffic with OGX
* Invoke mortgage domain tools through the MCP gateway
* Trace and evaluate agent quality with MLflow
* Enforce AI safety with NeMo Guardrails and OpenShell sandboxing

== How to use this guide

Work through each module in order. All infrastructure is pre-provisioned — no local setup is required. Use the browser tabs provided in your Showroom environment.
